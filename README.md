# Homebrew Tokcat

Homebrew tap for Tokcat.

## Install

```sh
brew tap handlecusion/tokcat
brew install --cask tokcat
```

The `tokcat` cask installs the macOS menubar app. It has no token-usage CLI
dependency; Tokcat reads supported local AI coding session logs directly.

After installation, open Tokcat from Applications. It runs in the macOS menu
bar and visualizes local AI token usage on-device.

## Packages

- `tokcat` cask: macOS menubar app, sourced from the `tokcat` GitHub release
